## 📖 Overview

This directory contains the documentation and web source code for obtaining official Windows 10 and Windows 11 ISO (Disc Image) files directly from Microsoft's servers. Downloading official media ensures you get an untouched, secure, and malware-free copy of the operating system.

### What is covered in this guide:
1. **Windows 10 Download:** Downloading via the official Microsoft Media Creation Tool, selecting architecture settings, and generating the ISO file.
2. **Windows 11 Download:** Directly downloading the Multi-Edition ISO image from the browser, selecting regional languages, and verifying the downloaded package.

## 📌 Important Notes & Prerequisites

- **Official Source:** Always ensure you download Windows files only from official Microsoft portals to preserve system licensing and security integrity.
- **Internet Connection:** Since ISO files are large (ranging from 4.5 GB to 6.5 GB), a stable, high-speed internet connection is recommended.
- **Free Disk Space:** Keep at least **8 GB** of free space available on your local drive to save the downloaded image safely.
- **Next step preparation:** Have a USB flash drive of at least **8 GB** capacity ready for the bootable media creation process.
