Official Windows ISO
Download Guide

A step-by-step walkthrough to safely obtain untouched Windows 10 and Windows 11 ISO files directly from Microsoft's servers.

Select Windows Version

Toggle to see download instructions for Windows 10 or Windows 11.

Download Official Windows 10 Media Creation Tool Official Microsoft Download Page
Step 1

Create Windows 10 Installation Media Download

To get started, you will first need to have a license to install Windows 10. You can then download and run the media creation tool. For more information on how to use the tool, see the instructions below.

Microsoft Download Portal
Step 2

Run MediaCreationTool as Administrator

Go to the folder where your downloaded file is located, right-click, and run the MediaCreationTool executable. If the User Account Control (UAC) window appears, click "Yes" to allow the tool to start.

Media Creation Tool Launcher
Step 3

Accept License Terms

The wizard will load the setup configurations. Carefully read the applicable notices and license terms, then click "Accept" to proceed.

Windows 10 Setup - License Terms
Step 4

Choose What You Want to Do

Select the option "Create installation media (USB flash drive, DVD, or ISO file) for another PC". Do NOT choose "Upgrade this PC now" if you want a clean ISO file for bootable media. Click "Next".

Windows 10 Setup - Options
Step 5

Select Language, Architecture & Edition

Choose your preferred Language, Windows Edition, and Architecture (usually 64-bit (x64) is highly recommended for modern computers). After confirming, click "Next".

Windows 10 Setup - Language & Architecture
Step 6

Choose Which Media to Use

Choose "ISO file" as your media option and click "Next". This downloads the official file containing the operating system, which you can burn to a USB later using Rufus or Ventoy.

Note: If you were creating a direct bootable USB via this tool, it would erase the USB data. But by choosing "ISO file", nothing is erased on your storage devices yet.
Windows 10 Setup - Select Media
Step 7

Choose Download Folder

A file explorer window will open. Select the folder (e.g. Downloads or Desktop) where you wish to save the Windows 10 ISO image, name the file, and click "Save".

Windows 10 Setup - Save Path
Step 8

Downloading Windows ISO File

The tool will begin downloading the Windows 10 ISO file. This process may take some time depending on your internet connection speed. You can continue using your PC while the download runs in the background.

Windows 10 Setup - Download Progress
Step 9

Finish the Process

Once the download is finished and the tool verifies the files, click "Finish" to close the Media Creation Tool safely.

Windows 10 Setup - Verification Complete
Step 10

Verify ISO File Download

Open the target directory to verify that the Windows.iso file has been created successfully. Verify the size of the file (typically between 4GB and 6GB).

File Explorer - ISO Verified
Download Windows 11 Disk Image (ISO) Directly Official Microsoft Download Page
Step 1

Select Windows 11 Multi-Edition ISO

On the Microsoft Windows 11 download page, scroll down to the section titled "Download Windows 11 Disk Image (ISO) for x64 Devices". In the dropdown menu, select "Windows 11 (multi-edition ISO for x64 devices)", then click "Download Now".

Microsoft Edge - Choose Windows 11 ISO
Step 2

Select Product Language

A new section will appear asking to select the product language. Choose your preferred language (e.g., English (United States) or English International) and click "Confirm".

Microsoft Edge - Language Selection
Step 3

Download Windows 11 ISO File

A download link will be generated (valid for 24 hours). Click on the "64-bit Download" button to start downloading the Windows 11 ISO image file directly through your web browser.

Microsoft Edge - Direct Download Button
Step 4

Verify Downloaded ISO File

Monitor your browser's download manager. Once finished, navigate to your download directory and verify the ISO file. It will typically be named similarly to Win11_English_x64.iso and have a size of around 5GB to 6.5GB.

Browser Downloads History

ISO Download Complete!

Now that you have successfully downloaded the untouched Windows ISO file, proceed to the next step to create a bootable USB drive.

Bootable USB Setup
(Rufus Guide)

A step-by-step walkthrough to flash your Windows ISO onto a USB drive and bypass installation hardware checks.

Download Official Rufus Flashing Utility (Latest Version) Official Rufus Website

Select Target Windows OS

Configure settings for Windows 10 or Windows 11.

Step 1

Open Rufus Application

Go to the directory where your downloaded Rufus utility is located, and double-click to launch it. If the UAC popup appears, click "Yes" to allow it to run.

Rufus Launcher
Step 2

Insert and Detect USB Flash Drive

Insert your USB flash drive (minimum 8 GB capacity) into a USB port on your PC or laptop. Rufus will automatically detect and list the drive under the "Device" field.

Rufus - Device Selection
Step 3

Configure Rufus Settings

Select "Disk or ISO image" under Boot selection, click the "SELECT" button, and choose your downloaded Windows ISO file. Select GPT (UEFI standard) as the Partition scheme. Leave other settings at default and click "START".

Rufus - Setup Configuration
Step 4

Windows Customization Settings

Windows 10 customization dialog appears. Select "Create a local account with username" and configure it if needed. Then click "OK".

Rufus - Windows User Customization

USB Drive Data Erasure Warning

WARNING: Formatting will permanently destroy all existing files stored on the USB drive. Back up your files before clicking OK.

Confirm the format warning by clicking "OK" to begin writing files.

Rufus - Formatting Warning Dialog
Step 5

Creating the Bootable USB Drive

Rufus will format the drive and start writing the Windows files to the USB. The green progress bar at the bottom will track the process status. Do not unplug the USB drive.

Rufus - Copying Files
Step 6

Step 6 — Bootable USB Complete

Wait for the progress bar to reach 100%. Once the state changes to **READY**, your bootable USB is ready. Click **Close**.

Rufus - Flash Process Complete

Bootable USB Media Created!

Microsoft Activation
Scripts (MAS) Guide

An open-source Windows and Office activator featuring HWID, Ohook, TSforge, and Online KMS activation methods.

PowerShell Activation Method

RECOMMENDED
Step 1

Open the Start Menu

Click on the Windows Start menu or press the Windows key on your keyboard.

Step 2

Search for PowerShell

Type PowerShell in the search bar. There is no strict requirement for Administrator privileges for the recommended method, but running it as Administrator yields the best compatibility.

Step 3

Execute the Command

Copy and paste the command below into the PowerShell window, and then press Enter.

irm https://get.activated.win | iex

This fallback command resolves DNS queries via Cloudflare over HTTPS if standard connections are restricted. Requires an updated Windows 10/11 system.

iex (curl.exe -s --doh-url https://1.1.1.1/dns-query https://get.activated.win | Out-String)

Key Features

HWID Digital License

Permanently activate supported Windows 10/11 editions bound to your hardware.

Office Ohook

Permanently activate Microsoft Office suites locally without subscription checks.

Flexible KMS Activation

Standard 180-day activation for Windows & Office with automated renewal tasks.

Open Source & Clean

100% transparent batch script structure resulting in fewer antivirus detections.

Activations Summary

Activation Type Supported Products Activation Period Requires Internet?
HWID Windows 10, Windows 11 PERMANENT Yes

Important Notes

  • An active internet connection is mandatory to connect to the digital license validation endpoints.
  • Some antivirus software might flag the script due to heuristic signatures. Temporarily disable protection if the script is blocked.
  • Running PowerShell or MAS_AIO with administrator privileges resolves permissions issues.
  • Ensure system versions and editions match the chosen activation algorithms (HWID, Ohook, KMS, ESU).

Pro Tips

  • HWID (Hardware ID) method is recommended for permanent activation of supported Windows editions.
  • Use the Ohook method specifically for stable and permanent Microsoft Office suite activations.
  • Restart your machine after the activation reports success to ensure core system policies reload correctly.
  • Verify your system properties in Windows Settings or Office Account settings to confirm successful status.
