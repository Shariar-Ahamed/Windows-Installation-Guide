Why did this guide migrate?

Moving the Microsoft Activation Scripts instructions to a dedicated workspace allows us to:

  • Maintain script updates independently of the Windows installation lifecycle.
  • Ensure activation methods (like HWID, Ohook, and KMS) stay up to date with Microsoft licensing checks.
  • Track discussions, bug reports, or feature requests in a focused community environment.

Activation Methods Covered in MAS

HWID Activation

Provides permanent digital license activation for Windows 10 and Windows 11 editions. The activation survives system reinstalls and hard drive changes.

Ohook Activation

Enables permanent local activation for Microsoft Office suites and standalone applications without requiring KMS servers or periodic renewals.

Online KMS

Offers standard KMS activation for Windows and Office editions. It connects to trusted online KMS servers and auto-renews every 180 days.

TSforge & ESU

Bypasses and activates Extended Security Updates (ESU) licensing for legacy Windows editions and Enterprise Windows Server setups.
