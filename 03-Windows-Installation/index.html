Windows 11 Setup

Windows 11 Installation Full Process

Follow this detailed walkthrough containing 24 chronological steps to install and set up Windows 11.

Step 1

Open Motherboard Boot Menu

Restart your PC or laptop and continuously tap your motherboard's boot menu key to open the Boot Menu.

Example Motherboard: Gigabyte B450 AORUS PRO WIFI. The Boot Menu Key is F12.
💡 Note: If you don't know your boot key, search Google using your motherboard or laptop model name.

Motherboard Boot Menu Launcher
Step 2

Select Bootable USB Flash Drive

Choose your bootable USB flash drive from the boot selection list. Look for options labeled with UEFI followed by your flash drive model name.

Example Option: UEFI: USB3.0 FLASH DRIVE PMAP, Partition 1

Boot Device Selection
Boot Device Selection alternate
Step 3

Configure Language & Regional Settings

Select your installation language, time, and regional currency settings.

Language to install: English (United States)
Time and currency format: English (United States)

Click "Next" once they are configured correctly.

Windows Setup - Regional Configuration
Step 4

Select Keyboard input layout

Select your keyboard or input layout configuration.

Keyboard or input method: US

Click "Next".

Windows Setup - Keyboard Layout
Step 5

Select Windows 11 Installation Option

Choose "Install Windows 11". Make sure you check the consent box stating: "I agree everything will be deleted including files, apps, and settings" to prepare a clean disk setup. Then click "Next".

Windows Setup - Installation Consent
Step 6

Product Key Verification

If you possess a product activation key, type it in the text box. Otherwise, click on "I don't have a product key" to proceed and activate Windows later. Click "Next".

Windows Setup - Product Key Input
Step 7

Select Windows 11 Edition

Choose the specific edition of Windows 11 you intend to install.

Preferred Edition: Windows 11 Pro

Click "Next".

Windows Setup - Edition Selection
Step 8

Accept License Terms

Read through the licensing terms and notices carefully. Click the checkbox or option to **Accept** the agreement, then click "Next".

Windows Setup - License Agreement
Step 9

Partition Configuration & Drive Formatting

Select and format the partition where Windows 11 will be cleanly installed.

1. Select Primary Partition

Choose the target primary disk partition where you want to load the new operating system files.

Windows Setup - Partition Selector

2. Format the Partition

Click the "Format" action button. This will format the drive and clear previous system remnants to allow a clean setup.

Windows Setup - Format Tool

3. Select Partition Again & Continue

After formatting completes, highlight that same formatted partition again and click "Next".

Windows Setup - Continue Installation
Step 10

Review Settings Summary

Review the final summary configuration before executing the installer.

Selected Action: Install Windows 11 Pro — Keep nothing

Click "Install".

Windows Setup - Ready to Install
Step 11

Installing Windows 11

The file copying and extraction process will now launch. Please wait until progress reaches 100%.

⚡ Warning: Keep your computer powered on. Your PC may restart automatically several times.

Windows Setup - Writing Files

Important Notes & Requirements

Know Your Motherboard Boot Key

Each manufacturer defines a different boot key (like F12, F11, Esc, F8). Search Google with your motherboard/laptop model if you do not know yours.

Warning: Data Deletion

Formatting partitions in Step 9 will permanently wipe all previously stored data on that drive partition. Ensure your backups are ready.

Keep PC Plugged In

Make sure your PC or laptop has a stable power supply and is kept powered on during the entire installation process to prevent file corruption.

Bypass Microsoft Account Setup

If you don't have internet or want to use a local account, click "I don't have internet" in Step 19 to bypass the Microsoft Account requirement.

Next Step: Activation Scripts

After completing installation, proceed to the Microsoft Activation Scripts (MAS) folder to activate Windows, Office, and ESU updates.
