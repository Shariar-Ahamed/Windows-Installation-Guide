## 📖 Overview

This directory contains the documentation and web source code for carrying out a clean installation of the **Windows 11** operating system using a bootable USB flash drive. It covers everything from booting into setup to partitioning drives and configuring offline accounts.

### What is covered in this guide:
1. **Boot Menu & USB Selection:** Accessing the motherboard boot settings and selecting the bootable media.
2. **Language & Keyboard Selection:** Configuring language, time, and currency layout.
3. **Partitioning and Formatting:** Cleaning previous system files, formatting partitions, and starting the installation.
4. **Out-of-Box Experience (OOBE):** Region setup, keyboard options, and offline account configuration.
5. **Internet Connection Bypass:** Skipping the mandatory Microsoft Account login to set up a local user.
6. **Desktop Completion:** Completing loading sequences and entering the Windows desktop.

## 📌 Important Notes & Requirements

- **Know Your Boot Menu Key:** Each motherboard/laptop manufacturer uses a different key (e.g., F12, F11, Esc, F8) to trigger the boot selection screen. Check online with your model if unsure.
- **Data Erasure Warning:** Formatting partitions during installation will permanently erase all previously stored data on that partition. Create backups before formatting.
- **Power Connection:** Keep your device plugged into a power source and turned on during the copy process to prevent data corruption.
- **Offline Account Setup:** You can bypass mandatory Microsoft account requirements by choosing "I don't have internet" during setup to use local profiles.
- **Post-Install Activation:** Once setup completes, proceed to the Microsoft Activation Scripts section to activate your licensing.
