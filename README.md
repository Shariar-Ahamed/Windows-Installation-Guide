- Official Windows ISO documentation

- Complete installation workflow

---

## ⚠️ Important Notes

- Always back up your important data before installation
- Use at least an 8GB USB drive
- Follow steps in order (1 → 2 → 3)
- Do not skip BIOS/boot settings section
